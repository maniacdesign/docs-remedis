| Variable                                 | Cara Pengisian                                                                             |
| ---------------------------------------- | -------------------------------------------------------------------------------------------| 
| Anemis (Kepala)                          | Pilih (+) jika konjungtiva mata pucat, (-) jika kemerahan normal.                          |
| Icteric                                  | Pilih (+) jika bagian putih mata (sklera) berwarna kuning, (-) jika putih bersih           |
| Sinosis (Kepala)                         | Pilih (+) jika bibir atau kulit kebiruan (kurang oksigen), (-) jika warna kulit normal     |
| Dispneu (Kepala)                         | Pilih (+) jika ada sesak napas atau penggunaan otot bantu napas, (-) jika napas tenang     |
| Lain - Lain (Kepala)                     | Tuliskan temuan abnormal lain di area kepala/leher (misal: luka robek, benjolan).          |
| Simetris / Asimetris (Thorax)            | Pilih Simetris jika gerakan dada kanan & kiri sama saat bernapas                           |
| Retraksi (thorax)                        | Pilih (+) jika ada tarikan dinding dada ke dalam saat bernapas, (-) jika tidak ada         |
| Perkusi                                  | Pilih Sonor (normal), Redup (ada cairan/massa), atau Hipersonor (udara berlebih).          |
| Suara veskuler                           | Pilih Normal, Meningkat, Menurun, atau Negatif (tidak terdengar)                           |
| Rhonki                                   | Pilih (+) jika terdengar suara napas "kasar" atau seperti berlendir, (-) jika bersih.      |
| Wheezing                                 | Pilih (+) jika terdengar suara "ngik" (penyempitan jalan napas), (-) jika tidak ada        |
| Suara Jantung (Jantung)                  | Pilih Reguler jika detak jantung beraturan, Irregular jika tidak beraturan.                |
| Ekstremitas                              | Klik pilihan sesuai kondisi pasien.                                                        |                   
| Lain - Lain                              | Isi kolom sesuai kondisi pasien.                                                           |
