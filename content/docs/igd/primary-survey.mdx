| Variable                                                      | Cara Pengisian                                                                                                                  |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Triase Primer                                                 | Pilih jenis triase pada kolom P1/P2/P3                                                                                          |
| Tanda - tanda Vital                                           | Diisi tanda-tanda vital seperti : GCS, Tekanan Darah, Respiratory Rate, Akral, Pupil, Nadi, SO2, Suhu Tubuh, Reflex Cahaya      |
| Status Alergi                                                 | Pilih tidak/ya, jika ya tulis alergi pasien.                                                                                    |
| Resiko Infeksi                                                | Pilih tidak/ya, jika ya tulis infeksi apa yang terjadi pada pasien                                                              |
| Gangguan Perilaku                                             | Pilih salah satu sesuai kondisi pasien                                                                                          |
| Penanggung Jawab                                              | Diisi dengan nama petugas yang melakukan asesmen                                                                                |
