| Variable                                 | Cara Pengisian                                                             |
| ---------------------------------------- | -------------------------------------------------------------------------- |
| Triase Primer                            | Pilih jenis triase pada kolom P1/P2/P3                                     |
| Tanda - tanda vital                      | Diisi dengan hasil pemeriksaan tanda-tanda vital                           |
| Status Alergi                            | Pilih Tidak/Ya, Jika 'Ya' maka tuliskan alergi pasien .                    |
| Resiko Infeksi                           | Pilih Tidak/Ya, Jika 'Ya' tulis infeksi apa yang terjadi pada pasien.      |
| Gangguan Perilaku                        | Pilih salah satu sesuai kondisi pasien.                                    |
| Penanggungjawab                          | Diisi dengan nama petugas yang melakukan asesmen                           |
