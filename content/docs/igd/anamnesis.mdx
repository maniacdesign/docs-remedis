| Variable                         | Cara Pengisian                                                                                                                                                                                          |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Up Triase                        | Pilih jenis triase pada kolom P1/P2/P3/P4                                                                                                                                             |
| Keluhan utama:                   | Diisi dengan keluhan utama pasien, Contoh : Nyeri perut bagian bawah disertai mual sejak tadi pagi.                                                                 |                                                                
| Riwayat alergi                   | Diisi dengan Riwayat alergi pasien, Contoh : Obat antalgin (reaksi bengkak pada mata).  |
| Riwayat penyakit                 | pilih “tidak ada” jika tidak ada Riwayat penyakit, pilih “ada” jika ada Riwayat penyakit lalu sebutkan Riwayat penyakitnya, Contoh : Gastritis kronis dan riwayat operasi Caesar (SC) tahun 2022.                                                                                                                                            |
