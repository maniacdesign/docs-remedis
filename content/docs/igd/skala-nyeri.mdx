| Variable                         | Cara Pengisian                                                                                                                                          |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Lokasi nyeri                     | Diisi dengan bagian yang merasakan nyeri.                                                                                                               |
| Lama Nyeri                       | Diisi dengan berapa lama nyeri. Pilih menit/jam/hari                                                                                                    |
| Frekuensi nyeri                  | Pilih sering/hilang itmbul/terus-menerus.                                                                                                               |
| Menjalar                         | Pilih sering/hilang itmbul/terus-menerus.                                                                                                               |
| Saat                             | Pilih minum obat/istirahat/mendengarkan musik/berubah posisi tidur/lain-lain. Jika lain-lain, sebutkan.                                                 |
| Kualitas Nyeri                   | Pilih tumpul/tajam/panas                                                                                                                                |
| Beritahukan ke dokter            | Pilih ya/tidak                                                                                                                                          |
