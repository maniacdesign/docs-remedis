| Variable                         | Cara Pengisian                                                                                                    |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Pengkajian fungsi                | Pengkajian aktifitas sehari-hari. Pilih sesuai kondisi pasien yaitu mandiri/dengan bantuan                        |
| Pengkajian resiko pasien jatuh   | Pilih ya/tidak sesuai dengan kondisi pasien                                                                       |
| Pengkajian resiko dekubitus      | Pilih ya/tidak sesuai dengan kondisi pasien                                                                       |
| Khusus anak                      | Diisi jika pasien anak-anak.                                                                                      |
| Status kehamilan                 | Pilih tidak hamil/hamil, jika hamil isi kolom gravida, abortus dan hpht.                                          |
| Penanggungjawab                  | Diisi dengan nama petugas yang melakukan asesmen.                                                                 |
