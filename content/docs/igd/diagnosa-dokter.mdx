| Variable                                 | Cara Pengisian                                                                                                                                                                                                                     |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | 
| Diagnosa Kerja                           | Diagnosis awal yang dianggap paling mungkin benar oleh dokter berdasarkan data awal. Contoh : Obs. Dyspnea + Ascites + Nefrolithiasis (post op, terpasang kateter flank D/S) + riw. CKD (HD terakhir bulan Agustus) + Anemia       |
| Diagnosa Banding                         | Daftar kemungkinan penyakit lain yang memiliki gejala atau tanda klinis serupa. Contoh : Congestive Heart Failure (CHF) NYHA III-IV, Pneumonia Aspirasi                                                                            |
