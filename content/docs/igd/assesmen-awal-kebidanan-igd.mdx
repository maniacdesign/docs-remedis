| Variable                                 | Cara Pengisian                                                                                         |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Informasi didapat dari                   | Dipilih sesuai jenis anamnesa, jika allo-anamnesa maka tulis nama dan hubungan dengan pasien           |
| Cara masuk                               | Dipilih yang sesuai cara masuk pasien                                                                  |
| Alasan Rujuk                             | Diisi alas an pasien dirujuk.                                                                          |
| Riwayat Penyakit Sekarang                | Diisi dengan Riwayat penyakit pasien yang sekarang                                                     |
| Riwayat ANC                              | Diisi dengan HPHT, pengobatan selama hamil dan lab. Selama hamil.                                      |
| Riwayat Penyakit Dahulu                  | Diisi dengan Riwayat penuakit pasien yang terdahulu.                                                   |
| Riwayat Kehamilan dan Persalinan Lalu    | Diisi dengan Riwayat kehamilan dan persalinan pasien sebelumnya                                        |
| Terapi sebelum MRS                       | Diisi terapi yang dilakukan pasien sebelum MRS.                                                        |
