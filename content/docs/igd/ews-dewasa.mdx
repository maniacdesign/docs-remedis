| ---------------------------------------- | -------------------------------------------------------------------------------------------------- | 
| Tanggal                                  | Diisi dengan tanggal pengisian Early Warning Scoring System (Dewasa)                               |
| Jam                                      | Diisi dengan jam pengisian Early Warning Scoring System (Dewasa)                                   |
| Laju reprasi/menit                       | Diisi dengan Keberadaan sesak napas (dispneu) atau penggunaan otot bantu napas.                    |
| Saturasi O2                              | Diisi dengan hasil pengukuran saturasi dengan oximeter                                             |
| Suplemen O2                              | Diisi dengan suplemen O2                                                                           |
| Temperatur (°C)                          | Diisi dengan hasil pengukuran suhu tubuh pasien dengan termometer                                  |
| Tekanan darah sistolik (mmHg)            | Diisi sesuai hasil pengukuran tekanan darah pasien                                                 |
| Tekanan darah diastole (mmHg)            | Diisi sesuai hasil pengukuran tekanan darah pasien                                                 |
| Laju detak jantung/menit                 | Diisi dengan frekuensi berapa kali jantung berdetak dalam satu menit (BPM - Beats Per Minute)      |
| Kesadaran                                | Diisi sesuai tingkat kesadaran pasien                                                              |
