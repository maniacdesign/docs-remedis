| Variable                                   | Cara Pengisian                                                                                                                       |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| Kondisi pasien saat pindah/pulang dari IGD | Pilih salah satu kondisi pasien saat pulang atau pindah dari IGD. Contoh : Masuk rumah sakit/Tindakan lanjutan di/Pulang/Meninggal   |
| Jenis Diagnosa                             | Pilih kategori diagnosa yang ditegakkan Contoh : Diagnosa Utama, Diagnosa Sekunder, atau Komplikasi.                                 |
| Kode ICD X                                 | Diisi dengan kode klasifikasi penyakit internasional yang sesuai dengan diagnosa pasien                                              |
| Kasus                                      | Tentukan apakah ini merupakan Kasus Baru atau Kasus Lama/Kontrol.                                                                    |
| Catatan                                    | Tambahkan keterangan tambahan atau ringkasan penting mengenai riwayat penanganan selama di IGD.                                      |
| DPJP                                       | Diisi nama Dokter Penanggung Jawab Pelayanan yang menangani pasien.                                                                  |
| Penanggung Jawab (perawat)                 | Diisi dengan nama perawat yang bertanggung jawab mendampingi proses pemulangan atau pindah ruangan.                                  |
| Follow Up                                  | Diisi dengan rencana tindak lanjut (misal: kontrol poli, rujuk balik, atau instruksi perawatan di rumah).                            |
| Hasil                                      | Diisi dengan hasil akhir pelayanan (misal: Sembuh, Membaik, Meninggal, atau Atas Permintaan Sendiri).                                |
