| Variable                                 | Cara Pengisian                                                                             |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------| 
| Ukuran Antropometiri                     | Isi dengan angka berat badan (Kg) dan tinggi badan (cm) pasien saat ini                      |
| Inpeksi                                  | Pengamatan visual pada area perut, payudara, atau adanya luka/bekas operasi.                 |
| Palpasi                                  | Pemeriksaan perabaan pada area abdomen secara umum sebelum manuver Leopold.                  |
| Leopold I                                | Isi angka Tinggi Fundus Uteri (TFU) dalam cm dan tentukan bagian janin di fundus (lain-lain) |
| Leopold II                               | Menentukan bagian janin di sisi kanan dan kiri perut ibu.                                    |
| Leopold III                              | Menentukan bagian terbawah janin (presentasi) dan apakah sudah masuk panggul.                |
| Leopold IV                               | Mengukur sejauh mana bagian terbawah masuk pintu atas panggul (biasanya format perlimaan).   |
| Auskultasi                               | Mendengarkan Detak Jantung Janin (DJJ) menggunakan Doppler atau Laennec.                     |
| Perkusi                                  | Pemeriksaan ketuk, biasanya untuk mengecek refleks patella pada kasus preeklamsia.           |
| Pemeriksaan Dalam                        | Hasil pemeriksaan vagina (VT) jika ada indikasi persalinan.                                  |
| Pemeriksaan Gynekologi                   | Pemeriksaan khusus organ reproduksi jika pasien tidak hamil atau ada kelainan.               |

| Variable                                                      | Cara Pengisian                                                                                                                                                                                                                                   |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Ukuran antropometri                                           | Diisi dengan Tinggi Badan (TB) dan Berat Badan (BB). Contoh : BB:65  TB : 168                                                                                                                                                                    |                                                                                                                                                        |
| Inspeksi                                                      | Isi kolom sesuai kondisi pasien. Contoh : Wajah tidak pucat, tidak ada oedema. Payudara simetris, puting menonjol, kolostrum (+). Perut membesar sesuai usia kehamilan, tidak ada luka bekas operasi. Ekstremitas bawah tidak varises            |
| Palpasi                                                       | Diisi dengan Perabaan Leopold, seperti tinggi fundus, letak punggung, posisi bayi,                                                                                                                                                               |
| Auskultasi                                                    | Diisi sesuai hasil pemeriksaan detak jantung, suara nafas, dan pencernaan dengan menggunakan stetoskop.                                                                                                                                          |
| Perkusi                                                       | Diisi sesuai hasil Refleks Patella (ketukan pada lutut)                                                                                                                                                                                          |
| Pemeriksaan dalam                                             | Diisi dengan hasil pemeriksaan dalam. Contoh : Vagina tenang, portio tipis lunak, pembukaan 6 cm, ketuban utuh (+), presentasi kepala, posisi UUK (ubun-ubun kecil) kiri depan, tidak ada molase, bagian terbawah di Hodge III                   |
| Pemeriksaan gynekologi                                        | Diisi Isi kolom sesuai kondisi pasien. Contoh : Perut tampak datar, tidak ada luka bekas operasi. Area vulva/vagina tidak ada massa, tidak ada tanda-tangan peradangan, fluor albus (keputihan) sedikit warna bening                             |
| Pemeriksaan penunjang                                         | Diisi sesuai pemeriksaan penunjang yang dilakukan pasien                                                                                                                                                                                         | 
| Status psikologis                                             | Klik pilihan sesuai kondisi pasien                                                                                                                                                                                                               |
| Resiko jatuh                                                  | Klik pilihan sesuai kondisi pasien                                                                                                                                                                                                               |
| Edukasi yang diberikan                                        | Isi kolom sesuai kondisi pasien                                                                                                                                                                                                                  |
| Respon terhadap edukasi yang diberikan                        | Isi kolom sesuai kondisi pasien                                                                                                                                                                                                                  |
| Pemeriksaan selesai tanggal                                   | Isi tanggal pemeriksaan selesai                                                                                                                                                                                                                  |
| Jam                                                           | Diisi jam pemeriksaan                                                                                                                                                                                                                            | 
| Tindakan                                                      | Diisi tindakan yang dilakukan oleh pasien                                                                                                                                                                                                        |
