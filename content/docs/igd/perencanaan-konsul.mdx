| Variable         | Cara Pengisian                                                                                 |
| ---------------- | ---------------------------------------------------------------------------------------------- |
| Tanggal          | Diisi dengan tanggal dilakukannya permintaan konsultasi                                        |
| Jam              | Diisi dengan waktu (jam dan menit) saat draf konsul dibuat                                     |
| No. RM           | Nomor Rekam Medis pasien yang akan dikonsultasikan (otomatis sesuai data pasien)               |
| Unit             | Diisi dengan unit asal pengirim konsul (misal: IGD atau PONEK)                                 |
| Dokter           | Nama dokter pengirim/DPJP yang meminta konsultasi.                                             |
| Status           | Status urgensi konsul (misal: CITO untuk segera atau Biasa).                                   |
| Kd Konsul        | Kode unik referensi konsultasi yang dihasilkan oleh sistem.                                    |
| Pertanyaan       | Diisi dengan rincian temuan klinis dan pertanyaan spesifik yang diajukan kepada konsultan.     |
| Jawaban          | Bagian yang akan diisi oleh dokter konsultan setelah memeriksa pasien atau meninjau kasus.     |
