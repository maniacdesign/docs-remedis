| Variable         | Cara Pengisian                                                                                         |
| ---------------- | ------------------------------------------------------------------------------------------------------ |
| Tanggal          | Diisi dengan tanggal saat pemantauan/observasi dilakukan.                                              |
| Jam              | Diisi dengan waktu spesifik saat pengambilan data tanda-tanda vital                                    |
| Tekanan Darah    | Diisi dengan hasil pengukuran tekanan darah sistolik dan diastolik (mmHg)                              |
| Respiratory Rate | Diisi dengan frekuensi pernapasan pasien dalam satu menit.                                             |
| Nadi             | Diisi dengan frekuensi denyut nadi pasien per menit.                                                   |
| Suhu             | Diisi dengan nilai suhu tubuh pasien dalam derajat Celcius.                                            |
| SO2              | Diisi dengan persentase saturasi oksigen darah pasien (SpO2).                                          |
| O2               | Diisi dengan jumlah aliran oksigen yang diberikan (Liter/menit) jika pasien menggunakan alat bantu.    |
| Skala GCS        | Diisi dengan skor Glasgow Coma Scale pada mata, suara, dan gerakan untuk menilai tingkat kesadaran.    |
| Urine            | Diisi dengan jumlah volume produksi urine pasien (cc/ml).                                              |
| WSD              | Diisi dengan observasi cairan atau undulasi pada alat Water Sealed Drainage (jika terpasang).          |
| NGT              | Diisi dengan volume atau warna cairan yang keluar melalui Nasogastric Tube.                            |
