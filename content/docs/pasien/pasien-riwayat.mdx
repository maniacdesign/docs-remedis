| Variable                            | Cara Pengisian                                                                                                                                                                                |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Fitur Cari Pasien                   | Inputkan nama pasien untuk melakukan pencarian riwayat pasien                                                                                                                                 |
| Toggle Switch                       | Fitur ini hanya terdapat pada tampilan dokter dan digunakan untuk memfilter pasien dokter bersangkutan                                                                                        |
| Filter Tanggal                      | Pilih rentang tanggal awal hingga tanggal akhir agar pengguna dapat menampilkan riwayat sesuai periode waktu yang diinginkan                                                                  |
| Dashboard                           | Frame dashboard nantinya akan menampilkan formulir rawat inap yang telah dipilih                                                                                                              |
