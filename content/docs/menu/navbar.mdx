| Variable                           | Fungsi                                                                                                                                                                                                           |
| ---------------------------------- | -----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Garis Tiga (Sidebar)               | Terletak di pojok kiri paling ujung, berfungsi untuk membuka atau menyembunyikan bilah menu samping (sidebar) utama sistem.                                                                                      |
| Pencarian (Search Bar)             | Kolom teks di tengah yang berfungsi untuk mencari data pasien, nomor rekam medis, atau menu spesifik secara cepat di seluruh sistem.                                                                             |
| Icon Togle Pasien                  | Diisikan dengan riwayat pasien saat ini atau kejadian terbaru yang dialami oleh pasien.                                                                                                                          |
| Icon Resep                         | Akses cepat untuk resep atau melakukan pemesanan resep.                                                                                                                                                          |
| Icon Laboratorium                  | Akses cepat untuk melihat hasil pemeriksaan laboratorium pasien atau melakukan pemesanan pemeriksaan lab.                                                                                                        |
| Icon Radiologi                     | Akses untuk melihat hasil pencitraan medis (USG, Rontgen, CT-Scan) atau mengirim order ke unit radiologi.                                                                                                        |
| Internal Email                     | Fitur dalam proses pembuatan                                                                                                                                                                                     |
| Intrnal Messenger                  | Fitur dalam proses pembuatan.                                                                                                                                                                                    |
| Notifikasi                         | Memberikan peringatan atau pemberitahuan jika ada tugas baru, hasil lab yang sudah keluar, atau verifikasi yang tertunda.                                                                                        |
| Profil pengguna                    | Menampilkan nama tenaga medis yang sedang masuk (dalam gambar: Fiqi Isnaini Nurul Hikmah, dr. Sp.A) Jika diklik, akan muncul menu tambahan seperti Set Status, Profil & Akun, Tanda Tangan, Settings, dan Logout.|
