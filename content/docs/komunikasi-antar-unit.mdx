| Variable                                                                                              | Cara Pengisian                                                                                                                                                      |
| ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------  |
| Tanggal Terima                                                                                        | Pilih tanggal dan jam pasien diterima di unit tujuan. Harus sesuai waktu real                                                                                       |
| Dari Ruang                                                                                            | Pilih ruang pasien berasal. Contoh : IGD, Ruang Mawar, Kulit & Kelamin                                                                                              |
| Kesadaran / Orientasi , Tanda Vital, Skala Nyeri, Pemeriksaan Fisik, Tindakan Yang Sudah Dilakukan    | Terisi otomatis dari pemeriksaan fisik atau CPPT sebelumnya. Tidak diinput manual.                                                                                  |
| Pemeriksaan Penunjang                                                                                 | Isi “-” jika tidak ada. Jika ada → tulis singkat jenis penunjang. Contoh: Rontgen thorax, EKG.                                                                      |
| Persyaratan Klaim                                                                                     | Pilih salah satu: Lengkap atau Belum, Sebutkan. Jika Belum, sistem membuka kolom Keadaan Persyaratan Klaim Belum untuk dijelaskan (misal: “resume belum dibuat”).   |
| Mobilitas / Risiko Jatuh                                                                              | Pilih: Tidak Ada, Ringan, atau Tinggi. Jika “Ringan” atau “Tinggi”, sistem membuka kolom tambahan untuk dijelaskan.                                                 |
| Informasi Lain                                                                                        | Diisi informasi penting yang perlu diketahui ruang penerima.                                                                                                        |
| Pengkajian Kondisi Terkini                                                                            | Isi kondisi terakhir pasien saat tiba di ruang penerima. Contoh: sesak, gelisah, lemah, nyeri.                                                                      |
| Diagnosa                                                                                              | Isi diagnosa keperawatan awal atau impresi klinis penerima. Contoh: resiko syok, gangguan perfusi, distress napas.                                                  |
| Yang Perlu Ditindaklanjuti                                                                            | Isi rencana lanjutan setelah diterima. Contoh: anamnesa keluhan px, obs TTV per jam, lapor DPJP.                                                                    |
